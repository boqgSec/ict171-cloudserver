# Configuring Fail2Ban

## Update the Server

First, ensure all packages are up to date before installing Fail2Ban

```bash
sudo apt update
```

---

# Now Install Fail2Ban

Now, install Fail2Ban using apt

```bash
sudo apt install fail2ban -y
```
