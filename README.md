# Project Overview

This project involves configuring and securing a cloud-hosted Ubuntu server using Microsoft Azure Infrastructure as a Service (IaaS). The purpose of this project is to showcase my practical skills on a Linux server, being able to administrate, script, troubleshoot, harden my webpage using cybersecurity, and cloud infrastructure management tools.
 
# Features:
- Ubuntu Server 24.02 LTS
- Nginx Web Server
- Custom domain using NameCheap
- HTTPS SSL encryption
- Fail2Ban Protection
- UFW Firewall
- Monitoring Script
